# Vivid Excursions 
It is a full-stack web application for managing, booking, and reviewing excursions. It includes user authentication, admin controls, dynamic form handling, filtering, pagination, and role-based access.



## Tech Stack
Frontend: React, TailwindCSS

Backend: Node.js, Express

Database: PostgreSQL

Authentication: JWT with Argon2 password hashing

Validation: express-validator

State Management: React Context API

## Features
### User Functionality
Signup & Login (JWT-based auth)

View all excursions with search & pagination

Register for excursions

Edit or cancel their own registrations

Leave reviews for completed excursions

### Admin Functionality
Create, update, and delete excursions (with dynamic dates)

View and manage all registrations

Update registration statuses (Pending, Confirmed, Canceled, Closed)

View all reviews

See paginated, searchable lists of excursions and registrations
